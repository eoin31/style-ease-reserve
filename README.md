# Style Booking

Crée une application web de réservation pour un salon de coiffure. Elle doit être très professionnelle et adaptée au téléphone.

Page d’accueil : style et tendance , présentation, prestations avec prix, horaires et bouton « Prendre rendez-vous ».

Réservation : le client choisit une prestation, une date, un créneau disponible, puis renseigne son prénom et son numéro de téléphone. Il reçoit une confirmation.

Crée également un tableau de bord administrateur permettant au coiffeur de voir les rendez-vous.

Pour l’instant, utilise des données fictives. Aucun paiement.

Utilise une interface moderne, simple et rapide.
